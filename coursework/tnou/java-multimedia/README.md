# TNOU MCA Practical Lab Programs

## Lab 4 - Internet Programming (Java)

### Practical Questions

1. **Q1_TemperatureConverter.java** - Converting Temperature in Fahrenheit into Celsius
2. **Q2_StudentMarkList.java** - Student Mark-List preparation
3. **Q3_ReverseAndSum.java** - Reverse and sum of individual digits
4. **Q4_FibonacciSeries.java** - Generate Fibonacci series
5. **Q5_Factorial.java** - Finding Factorial of a number
6. **Q6_PrimeNumber.java** - Check if number is prime
7. **Q7_SortingArray.java** - Sorting in Ascending and Descending order
8. **Q8_MatrixMultiplication.java** - Matrix Multiplication
9. **Q9_QuadraticEquation.java** - Finding roots of quadratic equation
10. **Q10_SphereVolume.java** - Volume of sphere (Class and Object)
11. **Q11_EmployeeSalary.java** - Employee salary Report (Array of Objects)
12. **Q12_StackOperations.java** - Stack Operations (Constructor)
13. **Q13_Palindrome.java** - Palindrome check (Abstract Class)
14. **Q14_ElectricityBill.java** - Electricity charge calculation (Multiple Inheritance)
15. **Q15_AreaCalculation.java** - Area of Triangle and Rectangle (Package, Interface)
16. **Q16_QueueException.java** - Queue implementation (Exception Handling)
17. **Q17_MultiThreading.java** - Multi-Threading (Extending Thread class)
18. **Q18_RailwayReservation.java** - Railway Reservation System (IO Streams)
19. **Q19_GraphicsComponents.java** - Display graphical components (Graphics class)
20. **Q20_ImageDisplay.java** - Display image (PixelGrabber Class)

### How to Compile and Run

```bash
cd java
javac Q1_TemperatureConverter.java
java Q1_TemperatureConverter
```

### Note
- For Q20, place a sample.jpg image in the same directory
- All programs use Scanner for input
- Programs are concise and ready for submission

## Lab 5 - Multimedia Systems

### Practical Questions

1. **Q1_EnvironmentMapSphere.java** - Transform environment map to sphere surface
2. **Q2_FillEllipsePattern.java** - Fill ellipse interior with pattern
3. **Q3_ChangePatternSize.java** - Change size of rectangular fill pattern
4. **Q4_ThickLinesCaps.java** - Display thick lines with different cap styles (Butt, Round, Square)
5. **Q5_BlinkingHighlight.java** - Implement highlighting as blinking operation
6. **Q6_ScanConvertEllipse.java** - Scan convert ellipse to solid color
7. **Q7_ReflectTriangle.java** - Reflect triangle w.r.t X-axis
8. **Q8_Animate2DObject.java** - Animate 2D object (Moving car)
9. **Q9_BallBouncing.java** - Ball bouncing with random numbers
10. **Q10_MovingCirclesLines.java** - Moving colored circles and random lines

### How to Compile and Run

```bash
cd multimedia
javac Q1_EnvironmentMapSphere.java
java Q1_EnvironmentMapSphere
```

### Note
- All programs use JFrame and Graphics2D
- Thread-based animations for smooth rendering
- Easy to remember and prepare for practical exams
