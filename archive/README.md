Start daily practice in [`interview/java`](../interview/java/README.md), not here.
This archive preserves prior attempts and imports without presenting every variant
as another question to finish.

- [`java/daim-interview-practice`](java/daim-interview-practice): remaining Java
  attempts, expanded concept explanations, incomplete integration snippets, and
  personal Java/AutoHotkey examples. Primary topic packages were moved out, not copied.
- [`java/few-interview-practice`](java/few-interview-practice): the earlier six-program collection.
- [`imports/Interview-Practise`](imports/Interview-Practise) and
  [`imports/PP`](imports/PP): original ZIP snapshots, kept unopened by the build.

Original exercise contents, old IDE files, and existing generated output have been
preserved. Archived IDE metadata may describe the old layout; only the root project's
active module configuration is maintained. These folders are **not** part of the
supported Java build and may contain unfinished programs, missing dependencies,
duplicate helper types, or outdated examples.

Use the [migration and duplicate-topic map](../docs/organization.md) to locate old
work. When reviewing an alternative, compare the idea and trade-offs rather than
copying it back into the active workspace under a numbered name.
